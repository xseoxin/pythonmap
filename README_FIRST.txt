📋 CO TO JEST?
═══════════════════════════════════════════════════════════════

Aplikacja do monitorowania pozycji Twojej firmy w wynikach
wyszukiwania Google Maps.

✅ Sprawdza pozycje dla wybranych fraz
✅ Wizualizuje wyniki na mapie
✅ Generuje raporty
✅ Automatyczne sprawdzanie według harmonogramu


🚀 JAK ZACZĄĆ? (3 PROSTE KROKI)
═══════════════════════════════════════════════════════════════

KROK 1: Zainstaluj Python
-------------------------
1. Otwórz: https://www.python.org/downloads/
2. Pobierz Python (kliknij żółty przycisk)
3. Uruchom instalator
4. ⚠️ WAŻNE: Zaznacz "Add Python to PATH" ⚠️
5. Kliknij "Install Now"
6. Zrestartuj komputer


KROK 2: Sprawdź czy Python działa
----------------------------------
Kliknij dwukrotnie na plik:
   >>> check_python.bat <<<

Jeśli zobaczysz numer wersji Python - OK!
Jeśli błąd - wróć do KROKU 1.


KROK 3: Zainstaluj aplikację
-----------------------------
OPCJA A (normalna instalacja):
   Kliknij prawym na: install_step_by_step.bat
   Wybierz: "Uruchom jako administrator"

OPCJA B (jeśli pip nie działa):
   Kliknij prawym na: install_with_python_pip.bat
   Wybierz: "Uruchom jako administrator"

Poczekaj 3-5 minut na instalację.


✅ GOTOWE! Uruchom aplikację
═══════════════════════════════════════════════════════════════

Kliknij dwukrotnie na:
   >>> run.bat <<<

❓ PROBLEMY?
═══════════════════════════════════════════════════════════════

Problem: "Python nie jest rozpoznawany"
Rozwiązanie:
  1. Odinstaluj Python
  2. Zainstaluj ponownie z "Add Python to PATH"
  3. Zrestartuj komputer

Problem: "pip NIE jest zainstalowany" ⚠️ CZĘSTY PROBLEM!
Rozwiązanie:
  1. Użyj: install_with_python_pip.bat (jako Administrator)
  2. Lub przeczytaj: PROBLEM_PIP.txt
  3. Lub uruchom: fix_pip.bat

Problem: Aplikacja się nie uruchamia
Rozwiązanie:
  1. Uruchom: install_step_by_step.bat jako Administrator
  2. Zobacz plik: pythonmap.log
  3. Przeczytaj: QUICKSTART_PL.md


🎯 PIERWSZE KROKI W APLIKACJI
═══════════════════════════════════════════════════════════════

1. Dodaj projekt (➕ Nowy Projekt)
   - Wpisz nazwę firmy z Google Maps
   - Znajdź współrzędne w Google Maps:
     * Kliknij prawym na lokalizację
     * Kliknij na współrzędne
     * Wklej do aplikacji

2. Dodaj frazy (📝 Zarządzaj Frazami)
   - Przykłady: "pizza", "restauracja włoska"

3. Sprawdź pozycje (▶️ Sprawdź Pozycje)
   - Poczekaj 2-10 minut

4. Zobacz wyniki:
   - Tabela z wynikami
   - 🗺️ Pokaż Mapę
   - 📄 Generuj Raport


💡 WSKAZÓWKI
═══════════════════════════════════════════════════════════════

✅ Na początek:
   - Siatka: 5x5 (szybko, 2-3 minuty)
   - Promień: 3-5 km
   - 2-3 frazy

✅ Optymalne ustawienia:
   - Siatka: 7x7 (5-8 minut)
   - Promień: 5 km
   - Sprawdzaj raz dziennie

⚠️ Unikaj:
   - Zbyt częstego sprawdzania (spam)
   - Siatki 12x12 bez proxy (za dużo zapytań)
