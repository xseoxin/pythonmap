📋 CO SIĘ STAŁO?

Python jest zainstalowany, ale pip (menedżer pakietów) nie jest
dostępny w PATH lub nie został poprawnie zainstalowany.


✅ SZYBKIE ROZWIĄZANIE (3 minuty)

┌───────────────────────────────────────────────────────────────────────┐
│  OPCJA 1: Użyj specjalnego instalatora (NAJŁATWIEJSZE)              │
└───────────────────────────────────────────────────────────────────────┘

   1. Znajdź plik: install_with_python_pip.bat

   2. Kliknij PRAWYM przyciskiem myszy

   3. Wybierz: "Uruchom jako administrator"

   4. Poczekaj na instalację (3-5 minut)

   5. Gotowe! ✓


┌───────────────────────────────────────────────────────────────────────┐
│  OPCJA 2: Napraw pip                                                 │
└───────────────────────────────────────────────────────────────────────┘

   1. Kliknij dwukrotnie na: fix_pip.bat

   2. Postępuj zgodnie z instrukcjami

   3. Po naprawie użyj: install_with_python_pip.bat


┌───────────────────────────────────────────────────────────────────────┐
│  OPCJA 3: Instalacja ręczna (dla zaawansowanych)                    │
└───────────────────────────────────────────────────────────────────────┘

   Otwórz wiersz polecenia (cmd) jako Administrator:

   1. Naciśnij: Windows + R
   2. Wpisz: cmd
   3. Kliknij prawym → "Uruchom jako administrator"

   Następnie wpisz po kolei:

   cd C:\ścieżka\do\pythonmap

   python -m pip install --upgrade pip

   python -m pip install -r requirements.txt

❓ DLACZEGO TO SIĘ STAŁO?

Możliwe przyczyny:

1. ❌ Podczas instalacji Python nie zaznaczono "Add Python to PATH"
   → pip nie został dodany do zmiennych środowiskowych

2. ❌ Python zainstalowany bez pip
   → Trzeba doinstalować pip

3. ❌ Python zainstalowany tylko dla użytkownika
   → PATH nie jest globalny

💡 PORADY NA PRZYSZŁOŚĆ

Jeśli w przyszłości będziesz instalował pakiety Python, a pip nie działa:

❌ Zamiast:
   pip install nazwa_pakietu

✅ Używaj:
   python -m pip install nazwa_pakietu

To zawsze działa! 👍
