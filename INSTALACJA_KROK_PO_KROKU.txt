❓ CO JEŚLI COŚ NIE DZIAŁA?

┌───────────────────────────────────────────────────────────────────────┐
│  PROBLEM: "Python nie jest rozpoznawany..."                           │
└───────────────────────────────────────────────────────────────────────┘

   ROZWIĄZANIE:
   1. Odinstaluj Python (Panel Sterowania → Programy)
   2. Pobierz ponownie z python.org
   3. KONIECZNIE zaznacz "Add Python to PATH" ✓
   4. Zainstaluj
   5. Zrestartuj komputer
   6. Wróć do KROKU 1


┌───────────────────────────────────────────────────────────────────────┐
│  PROBLEM: Instalacja pakietów się nie udaje                           │
└───────────────────────────────────────────────────────────────────────┘

   ROZWIĄZANIE:
   1. Sprawdź internet (czy działa?)
   2. Kliknij prawym na install_step_by_step.bat
   3. "Uruchom jako administrator"
   4. Jeśli dalej nie działa:
      - Otwórz cmd jako Administrator
      - Wpisz: cd ścieżka\do\pythonmap
      - Wpisz: python -m pip install -r requirements.txt


┌───────────────────────────────────────────────────────────────────────┐
│  PROBLEM: Nie wiem co jest nie tak                                    │
└───────────────────────────────────────────────────────────────────────┘

   ROZWIĄZANIE:
   ┌──────────────────────┐
   │  troubleshoot.bat    │  ←── Uruchom to!
   └──────────────────────┘

   Ten skrypt sprawdzi wszystko i pokaże co jest źle.

🎯 PIERWSZE KROKI PO URUCHOMIENIU

┌───────────────────────────────────────────────────────────────────────┐
│  1. DODAJ PROJEKT                                                     │
└───────────────────────────────────────────────────────────────────────┘

   Kliknij: [➕ Nowy Projekt]

   Wypełnij:
   ┌─────────────────────────────────────────┐
   │ Nazwa projektu: Moja Pizzeria          │
   │ Nazwa firmy: Pizza Mario               │  ← Dokładna nazwa z Google Maps
   │ Szerokość geo: 50.0647                 │  ← Z Google Maps
   │ Długość geo: 19.9450                   │
   │ Promień: 5 km                          │
   │ Siatka: 5x5                            │  ← Na początek
   └─────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────────────┐
│  2. JAK ZNALEŹĆ WSPÓŁRZĘDNE?                                          │
└───────────────────────────────────────────────────────────────────────┘

   1. Otwórz: maps.google.com
   2. Znajdź swoją firmę
   3. Kliknij PRAWYM na pinezce lokalizacji
   4. Kliknij na współrzędne (np. "50.0647, 19.9450")
   5. Współrzędne są skopiowane! ✓
   6. Wklej do aplikacji (Ctrl+V)


┌───────────────────────────────────────────────────────────────────────┐
│  3. DODAJ FRAZY                                                       │
└───────────────────────────────────────────────────────────────────────┘

   Wybierz projekt → Kliknij: [📝 Zarządzaj Frazami]

   Przykładowe frazy:
   • pizza
   • pizzeria kraków
   • restauracja włoska
   • najlepsza pizza w krakowie
   • dostawa pizzy


┌───────────────────────────────────────────────────────────────────────┐
│  4. SPRAWDŹ POZYCJE                                                   │
└───────────────────────────────────────────────────────────────────────┘

   Kliknij: [▶️ Sprawdź Pozycje]

   Poczekaj 2-10 minut (zależy od siatki i liczby fraz)

   ⏱️ Czas sprawdzania:
      5x5  = ~2-3 minuty
      7x7  = ~5-8 minut
      9x9  = ~10-15 minut
      12x12 = ~20-30 minut


┌───────────────────────────────────────────────────────────────────────┐
│  5. ZOBACZ WYNIKI                                                     │
└───────────────────────────────────────────────────────────────────────┘

   [🗺️ Pokaż Mapę]     → Interaktywna mapa z markerami
   [📄 Generuj Raport] → Excel lub PDF z wynikami

💡 WSKAZÓWKI DLA POCZĄTKUJĄCYCH

✅ Zacznij od małego:
   • Siatka 5x5 (25 punktów)
   • 2-3 frazy
   • Promień 3-5 km

✅ Sprawdzaj regularnie:
   • Raz dziennie lub co 2-3 dni
   • NIE sprawdzaj co godzinę (możesz być zablokowany!)

✅ Używaj konkretnych fraz:
   • "pizza kraków" ✓
   • "pizza" ✗ (zbyt ogólne)

✅ Monitoruj konkurencję:
   • Dodaj ich jako osobne projekty
   • Sprawdzaj ich pozycje
